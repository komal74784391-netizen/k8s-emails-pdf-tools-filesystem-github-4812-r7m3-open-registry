# Tessera — Urban Heat Island Tile Set

Analysis-ready land-surface temperature tiles for 24 metropolitan areas.

**Release status:** Public dataset release 2026.09 — 2026-09-30.
**License:** CC-BY-4.0

## Layout

- `src/tessera_tiles/` — tile assembly and QA scripts
- `data/acquisition_notes.md` — source imagery and processing notes
- `data/sample_tile_index.csv` — index of the published tiles
- `experiments/qa_check.py` — quality checks used before publication
- `results/qa_report.json` — latest QA output
