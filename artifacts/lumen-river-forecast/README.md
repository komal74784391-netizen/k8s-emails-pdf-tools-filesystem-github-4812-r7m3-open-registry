# Lumen — Seasonal River Flow Forecast

Seasonal streamflow forecasting models for regulated river basins.

**Release status:** Public release v0.9.4 — 2026-05-22.
**License:** BSD-3-Clause

## Layout

- `src/lumen/` — forecast model and post-processing utilities
- `data/gauge_observations_sample.csv` — sample gauge observations
- `experiments/backtest.py` — hindcast/backtest harness
- `results/backtest_metrics.json` — latest backtest metrics
