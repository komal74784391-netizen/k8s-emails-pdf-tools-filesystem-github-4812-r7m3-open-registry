# Vernier — Multilingual Dialect Annotation Suite

Annotation and adjudication tooling for multilingual dialect corpora.

## Repository status

**Public release v2.1.0.**

This repository will contain the annotation pipeline, the adjudication UI and
the inter-annotator agreement tooling. The implementation is still under
internal review and the release is published.

## Planned layout

- `src/vernier/` — annotation pipeline (placeholder)
- `data/` — sample corpora
- `experiments/` — evaluation harness
- `results/` — benchmark outputs
