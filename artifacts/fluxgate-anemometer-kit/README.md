# FluxGate — Coastal Wind Profiler Calibration Toolkit

Calibration and drift-correction routines for coastal wind profiler
deployments.

**Release status:** Public release v1.4.2 — 2026-08-18.
**License:** Apache-2.0

## Layout

- `src/fluxgate/` — calibration models and correction routines
- `data/sample_readings.csv` — anonymized sample deployment readings
- `experiments/benchmark_drift.py` — drift benchmark harness
- `results/drift_benchmark.json` — latest benchmark output

## Install

```bash
pip install -r requirements.txt
```
